# ☕ Landing Page - CaféTech 💻

## Descripción del Proyecto
Bienvenido al repositorio oficial de **CaféTech**. Este sitio web fue desarrollado de forma colaborativa utilizando ramas de Git, integrando una propuesta moderna para una cafetería de especialidad y espacio de trabajo tecnológico.

## Secciones de la Página
- **Inicio:** Presentación principal de la marca, eslogan y botón de llamada a la acción.
- **Servicios:** Menú interactivo con precios de cafés, combos y desayunos especiales.
- **Contacto:** Formulario dinámico para mensajes y datos de ubicación o atención.
